## 四、差异与说明

按"事实准确、不夸大"原则，如实列出与 PRD 的轻微口径差异（均非阻断项，不影响功能闭环）：

1. **4.3 匹配精度**：`get_matching_plan` 仍保留 exact→general/ordinary→plans[0] 降级 fallback，非 PRD 严格"区域+火灾类型"精确匹配；未匹配预案时前端仅提示，缺"报警上下文中手动关联执行"入口（BR-F3-01 后半段）。
2. **4.7 周期自动派单**：巡检任务仍为手动新增，未实现按日/周/月周期自动派单（BR-F7-01），属增强项。
3. **4.10 统计明细收口**：`/api/stats/alarms` 已收口为仅 supervisor，属权限收紧（符合 PRD），非减功能。
4. **4.1 坐标/长度**：坐标"落在区域边界内"现由服务端 `x/y Field(ge=0,le=100)` 强制，属"服务端强校验替代前端软约束"的收口。
5. **4.8 参演人数**：participants 为自由文本，非强制数值"参演人数"，轻微口径差异。
