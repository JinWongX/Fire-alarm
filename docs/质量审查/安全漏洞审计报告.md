## 四、残余说明

以下为如实记录的"建议态 / 后续加固项"，**均不计为未修复**，不影响"15/15 已处置"的结论：

### F-01 高危 · JWT 签名密钥硬编码且强度不足
- **类别/CWE**：认证 / 硬编码凭据（CWE-798 / CWE-321，OWASP A07:2021）
- **风险位置**：`backend/app/auth.py` 原 `SECRET_KEY = "fire-alarm-secret-key-change-me"`
- **触发条件**：攻击者获取到源码即可离线伪造任意用户的合法 JWT（含 `role` 字段），无需密码。
- **影响范围**：全系统所有以 JWT 认证的接口被冒用；可伪造 `supervisor` 角色完全接管；token 内 `role` 声明亦来自明文。

### F-02 高危 · 默认账户弱密码（admin/duty/maintain 均为 123456）
- **类别/CWE**：认证 / 弱口令（CWE-521，OWASP A07:2021）
- **风险位置**：`backend/app/seed.py`、`start.bat` 首次部署自动创建 `admin`/`duty`/`maintain`，密码均为 `123456`，`admin` 为 `supervisor`。
- **触发条件**：攻击者凭默认凭据即可登录最高权限账户。
- **影响范围**：系统被完全接管。

### F-03 高危 · 设备模块写接口缺乏角色校验（垂直越权）
- **类别/CWE**：授权 / 缺失功能级访问控制（CWE-862 / CWE-269，OWASP A01:2021）
- **风险位置**：`POST/GET /api/devices`、`PUT /api/devices/{id}`、`PUT /api/devices/{id}/status`、`DELETE /api/devices/{id}` 仅用 `get_current_user`，未用 `RoleDependency`。
- **触发条件**：低权限用户调用写接口。
- **影响范围**：越权修改设备状态、删除设备，破坏报警联动正确性与系统完整性。

### F-04 高危 · CORS 配置过宽且与凭据组合不规范
- **类别/CWE**：安全配置 / CORS（CWE-942 / CWE-346，OWASP A05:2021）
- **风险位置**：`backend/app/main.py` 原 `allow_origins=["*"]` + `allow_credentials=True` + `allow_methods=["*"]` + `allow_headers=["*"]`。
- **触发条件**：任意来源浏览器发起跨域认证请求。
- **影响范围**：配置层放宽同源策略，不符合 OWASP CORS 安全基线。

### F-05 中危 · 模拟报警接口无角色限制（越权写操作）
- **类别/CWE**：授权 / 缺失权限控制（CWE-862，OWASP A01:2021）
- **风险位置**：`backend/app/routers/alarms.py` `POST /api/alarms/simulate` 仅 `get_current_user`。
- **触发条件**：低权限用户调用 `simulate`。
- **影响范围**：低权限用户可反复触发"报警→联动"链路，污染设备状态、伪造联动记录。

### F-06 中危 · 登录接口无速率限制（暴力破解面）
- **类别/CWE**：认证 / 暴力破解缺乏防护（CWE-307，OWASP A07:2021）
- **风险位置**：`backend/app/routers/auth.py` `POST /api/auth/login` 无失败次数限制。
- **触发条件**：针对账户进行高频尝试。
- **影响范围**：账户被暴力破解风险高；爆破 `admin` 后系统被接管。

### F-07 中危 · OpenAPI 生产环境暴露
- **类别/CWE**：信息泄露 / 错误配置（CWE-200，OWASP A05:2021）
- **风险位置**：`backend/app/main.py` 未禁用文档，运行时确认 `/docs`、`/openapi.json`、`/redoc` 均可访问。
- **触发条件**：直接访问上述路径。
- **影响范围**：暴露系统完整 API 面，便于定向攻击。

### F-08 中危 · CSV / Excel 导出公式注入
- **类别/CWE**：注入 / 公式注入（CWE-1236 / CWE-138，OWASP A03:2021）
- **风险位置**：`backend/app/routers/stats.py` `GET /api/stats/export`；`_rows_for` 将 `scene`/`result`/`description` 等用户可控字段直接写入单元格。
- **触发条件**：管理/导出人员在本地 Excel 打开导出文件。
- **影响范围**：触发任意公式执行（客户端注入/信息外带）。

### F-09 中危 · JWT 存储于 localStorage（XSS 横向风险面）
- **类别/CWE**：敏感数据驻留 / 前端存储（CWE-922，OWASP A03:2021）
- **风险位置**：`frontend/src/api/client.js`、`frontend/src/context/AuthContext.jsx` 使用 `localStorage` 存储 token。
- **触发条件**：未来出现前端 XSS 或供应链脚本污染。
- **影响范围**：token 可被窃取，会话劫持；属"风险待命"项。

### F-10 低危 · 分页参数无上限（资源耗尽面）
- **类别/CWE**：输入校验 / DoS（CWE-770，OWASP A04:2021）
- **风险位置**：多处 `page_size` 未设上限，如 `routers/devices.py`、`routers/alarms.py`、`routers/linkage.py` 等。
- **触发条件**：构造超大 `page_size` 拉取全表数据。
- **影响范围**：内存/IO 放大。

### F-11 低危 · 响应安全头缺失
- **类别/CWE**：安全配置 / 缺失 HTTP 安全头（CWE-693 / CWE-1021，OWASP A05:2021）
- **风险位置**：`backend/app/main.py` 未配置安全响应头中间件。
- **触发条件**：浏览器直接访问应用响应。
- **影响范围**：提升 MIME 嗅探、frame 嵌入、跨站数据外带风险。

### F-12 信息级 · 依赖版本口径说明
- **位置**：`backend/requirements.txt`（多数 `>=` 无上限）、`frontend/package.json`（`^` 浮动）
- **说明**：`passlib[bcrypt]<4.1` 规避 passlib 与 bcrypt 4.1 已知告警；后端多数依赖无版本上限。
- **建议**：锁定关键依赖并生成锁文件；pip-audit / npm audit 纳入 CI。

### F-13 信息级 · 时间函数使用已弃用 UTC API
- **位置**：`backend/app/auth.py`、各 router 多处 `datetime.utcnow()`。
- **说明**：`datetime.utcnow()` 自 Python 3.12 弃用，且 JWT `exp` 依赖本地时钟。
- **建议**：统一改用 `datetime.now(timezone.utc)`；JWT 结合 `leeway` 处理时钟偏移。

### F-14 信息级 · 传输层未强制 HTTPS
- **位置**：`start.bat` 以 `http://localhost:8000`、`http://localhost:5173` 直启。
- **说明**：本地/开发 HTTP 无可厚非；生产明文会泄露密码与 Bearer token。
- **建议**：生产强制 HTTPS（TLS ≥ 1.2），网关终止 TLS。

### F-15 信息级 · 生产/开发环境混用种子数据与调试配置
- **位置**：`backend/app/main.py` lifespan 无条件调用 `seed`；`start.bat` 以开发方式启动。
- **说明**：无环境区分，`seed` 与演示数据在生产同样执行。
- **建议**：以环境变量区分环境；种子数据、演示账号仅在开发启用。
